# Store Sales Dashboard

An interactive Excel sales dashboard analyzing customer purchase behavior and order performance across multiple e-commerce channels. Built using Pivot Tables, slicers, and dynamic charts to enable segment-level analysis of sales, demographics, and order trends.

## Overview

This dashboard consolidates raw store sales data into a single interactive view, allowing quick exploration of sales trends, customer demographics, regional performance, and channel-wise distribution — all filterable by month, age group, and sales channel.

## Dashboard Features

**Interactive Filters (Slicers)**
- **Month** — January through June
- **Age Group** — Adult, Senior, Youth
- **Channel** — Ajio, Amazon, Flipkart, Meesho, Myntra, Nalli, Others

**Visualizations**
- **Sales vs Month** — Combo chart tracking order count and total sales amount across months
- **Man vs Women Sales** — Pie chart showing gender-wise sales distribution
- **Orders: Age vs Gender** — Bar chart comparing order share across age groups by gender
- **Order Status** — Pie chart breaking down orders by Cancelled, Delivered, Refunded, and Returned status
- **Top 5 State Sales** — Horizontal bar chart ranking top-performing states by sales
- **App vs Sales** — Pie chart showing sales distribution across e-commerce channels

## Sheets

| Sheet | Description |

- Microsoft Excel

## Key Insights Enabled

- Identify monthly sales trends and seasonality
- Compare purchasing patterns by gender and age group
- Track order fulfillment health via cancellation/return/refund rates
- Benchmark top-performing states
- Understand channel-wise sales contribution across 6+ e-commerce platforms

## How to Use

1. Download `Store Data.xlsx`
2. Open in Microsoft Excel (Pivot tables and slicers require Excel — limited support in Google Sheets)
3. Use the **Month**, **Age Group**, and **Channel** slicers on the Dashboard sheet to filter all visuals dynamically
4. Explore underlying pivot tables on their respective sheets for raw breakdowns
